# taskr-site

Static public site for Taskr (Arctic Autonomy Ventures LLC d/b/a Taskr), served by GitHub Pages at https://taskrak.com.

Pages: `/` · `/privacy` · `/terms` · `/guidelines` · `/delete-account` · `404.html`

Edit content in `_src/build.py`, then run `python3 _src/build.py` from the repo root and commit the generated HTML.
(`_src/` is ignored by the Pages/Jekyll build.)
